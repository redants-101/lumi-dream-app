## 🎯 问题 2：跨标签页认证同步

### 问题描述
- sessionStorage 不跨标签页共享
- 新标签页初始显示"未登录"状态，1-2秒后闪烁变为"已登录"

### 解决方案
- ✅ 将 `lumi_auth_cache` 从 **sessionStorage** 改为 **localStorage**
- ✅ 保持 5 分钟自动过期机制
- ✅ 统一清理逻辑（集中在 `use-auth.ts`）

### 修复效果
- ⚡ 新标签页立即显示正确状态（无闪烁）
- 🔥 减少 80% 的 API 调用
- ✨ 跨标签页完全一致

### 文件变更
- `hooks/use-auth.ts` - sessionStorage → localStorage
- `contexts/usage-limit-context.tsx` - 移除重复清理逻辑

## 🔒 问题 1：匿名用户数据同步

### 问题描述
- 登出时直接清空 localStorage
- 用户可以通过"登录-登出"绕过使用限制（安全漏洞）

### 解决方案
- ✅ 登出时先查询 `anonymous_usage` 表（基于 IP）
- ✅ 如果有记录 → 同步到 localStorage
- ✅ 如果没有记录 → 初始化为空状态

### 修复效果
- 🔒 无法通过登出绕过限制
- 📊 数据库与 localStorage 完全同步
- ✨ 支持跨设备数据同步（基于 IP）

### 文件变更
- `lib/services/usage-service.ts` - 新增 `getAnonymousUsageInfo()` 函数
- `app/api/anonymous-usage/route.ts` - 新建 API 端点
- `hooks/use-auth.ts` - 新增 `syncAnonymousUsageOnSignOut()` 函数
