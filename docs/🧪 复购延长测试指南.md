## 🧪 测试场景

### 场景 1：续费（最重要）⭐

**目标**：验证复购相同套餐会延长订阅时间

#### 步骤 1：首次购买

1. 访问 `/pricing`
2. 购买 **Basic Monthly**
3. 完成支付
4. 记录当前订阅结束时间

**查询当前订阅**：
```sql
SELECT 
  tier, 
  billing_cycle, 
  current_period_start,
  current_period_end,
  DATE(current_period_end) as end_date
FROM user_subscriptions 
WHERE user_id = 'your-user-id';
```

**预期结果**：
```
tier: basic
billing_cycle: monthly
end_date: 2025-12-10 (大约 30 天后)
```

#### 步骤 2：再次购买（复购）

**等待几分钟后**（或立即测试）：

1. 再次访问 `/pricing`
2. 再次购买 **Basic Monthly**
3. 完成支付

#### 步骤 3：观察日志

**关键日志**：

```bash
💳 [Webhook] Checkout completed: ch_xxxxx
🔄 [Webhook] Event type: Subscription renewal (same plan)

✅ [Webhook] Extending subscription from existing end date
   Old end: 2025-12-10T00:00:00.000Z
   New end: 2026-01-09T00:00:00.000Z  ← 延长了 30 天！
   Added: 30 days

✅ [Webhook] Subscription history recorded
   Event type: subscription_renewed
   Description: basic monthly subscription renewed (extended)
```

#### 步骤 4：验证数据库

```sql
-- 查询订阅记录
SELECT 
  tier,
  billing_cycle,
  DATE(current_period_start) as start_date,
  DATE(current_period_end) as end_date,
  EXTRACT(DAY FROM (current_period_end - current_period_start)) as days
FROM user_subscriptions 
WHERE user_id = 'your-user-id';
```

**预期结果**：
```
tier: basic
billing_cycle: monthly
end_date: 2026-01-09  ← 比原来延长了 30 天
days: 60              ← 约 60 天（30 + 30）
```

#### 步骤 5：验证历史记录

```sql
-- 查询最近两条历史记录
SELECT 
  event_type,
  tier,
  billing_cycle,
  description,
  DATE(period_end) as end_date,
  metadata,
  event_date
FROM subscription_history 
WHERE user_id = 'your-user-id'
ORDER BY event_date DESC 
LIMIT 2;
```

**预期结果**：
```
记录 1（最新）:
  event_type: subscription_renewed
  description: basic monthly subscription renewed (extended)
  end_date: 2026-01-09
  metadata: { 
    "old_tier": "basic", 
    "old_billing_cycle": "monthly",
    "old_period_end": "2025-12-10T00:00:00Z"
  }

记录 2（首次购买）:
  event_type: subscription_created
  description: basic monthly subscription created
  end_date: 2025-12-10
  metadata: null
```

## 📊 快速验证 SQL

### 一键查询当前状态

```sql
-- 查询用户订阅和最新历史
SELECT 
  us.tier,
  us.billing_cycle,
  DATE(us.current_period_start) as start_date,
  DATE(us.current_period_end) as end_date,
  EXTRACT(DAY FROM (us.current_period_end - us.current_period_start)) as total_days,
  sh.event_type as last_event,
  sh.description as last_description,
  DATE(sh.event_date) as last_event_date
FROM user_subscriptions us
LEFT JOIN LATERAL (
  SELECT * FROM subscription_history 
  WHERE user_id = us.user_id 
  ORDER BY event_date DESC 
  LIMIT 1
) sh ON true
WHERE us.user_id = 'your-user-id';
```

### 查询所有历史记录

```sql
SELECT 
  event_type,
  tier,
  billing_cycle,
  description,
  DATE(period_end) as period_end,
  metadata,
  DATE(event_date) as event_date
FROM subscription_history 
WHERE user_id = 'your-user-id'
ORDER BY event_date DESC;
```

## 🐛 常见问题

### 问题 1：日志未显示延长

**症状**：
```bash
✅ [Webhook] Starting new monthly period
# 没有显示 "Extending subscription"
```

**原因**：
- 服务器未重启
- 代码未更新

**解决**：
```bash
# 清除缓存
Remove-Item -Recurse -Force .next

# 重启
pnpm dev
```

---

### 问题 2：订阅未延长

**症状**：
```sql
-- 查询结果
period_end: 2025-12-10  -- 没有变化
```

**检查**：
```sql
-- 查看历史记录的 event_type
SELECT event_type FROM subscription_history 
WHERE user_id = 'xxx' 
ORDER BY event_date DESC 
LIMIT 1;
```

**如果是 `subscription_created`**：
- 说明系统认为是首次购买
- 可能是数据库中没有旧订阅记录

**如果是 `subscription_renewed`**：
- 检查 `period_end` 是否延长
- 可能是旧订阅已过期（从现在开始计算）

---

### 问题 3：元数据为空

**症状**：
```sql
metadata: null  -- 应该包含旧订阅信息
```

**原因**：
- 首次购买（正常）
- 或查询失败

**验证**：
```sql
-- 查看是否为首次购买
SELECT COUNT(*) FROM subscription_history 
WHERE user_id = 'xxx';

-- 如果只有 1 条，说明是首次购买（正常）
-- 如果有多条，检查最新记录的 metadata
```
