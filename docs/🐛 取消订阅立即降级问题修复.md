## 🔧 修复内容

### 修复 1: `/api/usage/route.ts`

```typescript
// ✅ 修复后
if (subscription && 
    (subscription.status === "active" || subscription.status === "canceled")) {
  const isNotExpired = new Date(subscription.current_period_end) > new Date()
  if (isNotExpired) {
    tier = subscription.tier  // 保留权限
  }
}
```

**逻辑**：
- Active 订阅 + 未过期 → 保留权限 ✅
- Canceled 订阅 + 未过期 → 保留权限 ✅
- Canceled 订阅 + 已过期 → Free ✅

---

### 修复 2: `/api/user-info/route.ts`

```typescript
// ✅ 修复后
if (subscriptionResult.data && 
    (subscriptionResult.data.status === "active" || 
     subscriptionResult.data.status === "canceled")) {
  const isNotExpired = new Date(subscriptionResult.data.current_period_end) > new Date()
  if (isNotExpired) {
    tier = subscriptionResult.data.tier
    subscription = subscriptionResult.data
  }
}
```

---

### 修复 3: `/api/subscription/manage/route.ts`

```typescript
// ✅ 添加过期检查
if (subscription.status === "canceled") {
  const isNotExpired = subscription.current_period_end && 
                      new Date(subscription.current_period_end) > new Date()
  
  if (!isNotExpired) {
    // 已过期：返回 Free
    return successResponse({
      tier: "free",
      status: "active",
    })
  }
  // 未过期：继续返回完整数据
}

return successResponse(subscription)
```

## ⚠️ 重要说明

### 取消 ≠ 立即失效

**Creem 的订阅模型**：
- 取消订阅：`status = "canceled"`, `auto_renew = false`
- **保留到期前权限**：`current_period_end` 不变
- 到期后自然过期：不再扣款

**我们的逻辑**（修复后）：
- ✅ `status === "canceled"` + 未过期 → 保留权限
- ✅ `status === "canceled"` + 已过期 → Free
- ✅ 符合 SaaS 行业标准
