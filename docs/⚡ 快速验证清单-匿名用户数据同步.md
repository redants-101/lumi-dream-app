# ⚡ 快速验证清单 - 匿名用户数据同步修复

## 🎯 1 分钟核心测试

### ✅ 测试：登出后数据同步

#### 步骤：
1. **清除所有数据**
   ```javascript
   // 在 Console 中运行
   localStorage.clear()
   ```

2. **匿名状态使用 3 次**
   - 访问 `http://localhost:3000`（未登录）
   - 使用梦境解析功能 **3 次**

3. **检查 localStorage**
   ```javascript
   JSON.parse(localStorage.getItem('lumi_usage_data_v2'))
   // 应该显示：{ dailyCount: 3, monthlyCount: 3, ... }
   ```

4. **登录账号**
   - 点击 "Sign In" → 使用 Google/GitHub 登录
   - 确认登录成功（看到用户头像）

5. **立即登出**
   - 点击用户头像 → "Sign out"
   - 观察 **Console 日志**

#### ✅ 预期结果：

**Console 日志必须包含**：
```
[Auth] 🚪 Starting sign out process...
[Auth] 📊 Fetching anonymous usage from database...
[UsageService] ✅ Anonymous usage found: daily=3, monthly=3
[Auth] ✅ Anonymous usage synced to localStorage: {...}
[Auth] ✅ User signed out successfully
```

**localStorage 检查**：
```javascript
JSON.parse(localStorage.getItem('lumi_usage_data_v2'))
```

**必须显示**：
```json
{
  "dailyCount": 3,
  "monthlyCount": 3,
  "lastUpdated": "2025-11-03T...",
  "day": "2025-11-03",
  "month": "2025-11"
}
```

**❌ 如果失败**：
- localStorage 显示 `dailyCount: 0` → 同步失败
- Console 没有 `✅ Anonymous usage synced` → API 未调用

## 🔍 详细检查（如果核心测试失败）

### 检查 1：API 端点是否可用

```bash
# 在终端运行
curl http://localhost:3000/api/anonymous-usage
```

**✅ 预期响应**：
```json
{
  "success": true,
  "data": {
    "hasRecords": true,
    "usage": {
      "dailyCount": 3,
      "monthlyCount": 3,
      ...
    }
  }
}
```

**❌ 如果返回 404**：
- 文件未创建：`app/api/anonymous-usage/route.ts`
- 重启开发服务器：`npm run dev`

---

### 检查 2：数据库表是否有数据

```sql
-- 在 Supabase SQL Editor 中运行
SELECT 
  ip_address,
  date,
  SUM(count) as total_count
FROM anonymous_usage
WHERE date = to_char(CURRENT_DATE, 'YYYY-MM-DD')
GROUP BY ip_address, date;
```

**✅ 预期结果**：
```
ip_address      | date       | total_count
----------------|------------|------------
xxx.xxx.xxx.xxx | 2025-11-03 | 3
```

**❌ 如果没有数据**：
- 检查后端是否正确记录使用数据
- 查看 `/api/interpret` 日志

---

### 检查 3：函数是否正确导出

```javascript
// 在 Console 中运行（登出前）
console.log('Testing API manually...')
fetch('/api/anonymous-usage')
  .then(r => r.json())
  .then(data => console.log('API Response:', data))
```

**✅ 预期**：
```json
{
  "success": true,
  "data": { "hasRecords": true, ... }
}
```

## 🐛 常见问题排查

### 问题 1：Console 显示 "Failed to fetch"

**原因**：API 端点不存在或服务器未运行

**解决**：
```bash
# 1. 确认文件存在
ls app/api/anonymous-usage/route.ts

# 2. 重启开发服务器
npm run dev
```

---

### 问题 2：数据库查询返回空

**原因**：`anonymous_usage` 表未创建或无数据

**解决**：
```sql
-- 1. 检查表是否存在
SELECT * FROM anonymous_usage LIMIT 1;

-- 2. 如果不存在，运行创建脚本
-- 见 docs/3.定价支付/anonymous_usage表结构.sql
```

---

### 问题 3：localStorage 仍然为 0

**原因**：`syncAnonymousUsageOnSignOut()` 未被调用

**检查代码**：
```typescript
// hooks/use-auth.ts 的 signOut 函数
const signOut = async () => {
  // ...
  await syncAnonymousUsageOnSignOut()  // ← 这行必须存在
  // ...
}
```

---

### 问题 4：控制台报 TypeScript 错误

**原因**：导入或类型定义错误

**解决**：
```bash
# 检查 Linter 错误
npm run lint

# 检查类型错误
npm run type-check
```
