## 📝 实现逻辑

### 核心函数：`getButtonText()`

```typescript
const getButtonText = (tier: string) => {
  // 1️⃣ Free 套餐：始终显示 "Get Started"
  if (tier === "free") {
    return "Get Started"
  }

  // 2️⃣ 未登录用户（Anonymous）：显示 "Subscribe Now"
  if (!user) {
    return "Subscribe Now"
  }

  // 3️⃣ Free 用户：显示 "Upgrade to X"
  if (!currentSubscription || currentSubscription.tier === "free") {
    const tierName = tier.charAt(0).toUpperCase() + tier.slice(1)
    return `Upgrade to ${tierName}`  // "Upgrade to Basic" 或 "Upgrade to Pro"
  }

  // 4️⃣ Basic/Pro 用户
  const tierLevel = { free: 0, basic: 1, pro: 2 }
  const currentLevel = tierLevel[currentSubscription.tier]
  const targetLevel = tierLevel[tier]

  if (targetLevel > currentLevel) {
    // 升级
    return `Upgrade to ${tierName}`
  } else if (targetLevel < currentLevel) {
    // 降级
    return `Downgrade to ${tierName}`
  }
}
```

```

tier = "free"?
├─ 是 → "Get Started"
└─ 否 ↓

未登录（!user）?
├─ 是 → "Subscribe Now"  ✅ Anonymous 用户
└─ 否 ↓

Free 用户（tier = "free"）?
├─ 是 → "Upgrade to Basic/Pro"  ✅ Free 用户
└─ 否 ↓

当前 tier vs 目标 tier：
├─ 升级 → "Upgrade to X"
├─ 降级 → "Downgrade to X"
```
