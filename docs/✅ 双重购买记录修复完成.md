# ✅ 双重购买记录修复完成

## 🔍 问题分析

### 问题现象

Free 用户首次购买 Basic，产生了 **2 条**历史记录：

```json
记录 1: {
  "event_type": "subscription_created",
  "period_end": "2025-12-10",  // 30 天
  "description": "basic monthly subscription created"
}

记录 2: {
  "event_type": "subscription_renewed",  // ❌ 不应该出现
  "period_end": "2026-01-09",  // 60 天（延长了）
  "description": "basic monthly subscription renewed (extended)",
  "metadata": {"old_tier": "basic", "old_period_end": "2025-12-10"}
}
```

**异常**：
- ❌ 首次购买却有 2 条记录
- ❌ 订阅被延长到 60 天（本应 30 天）
- ❌ 第 2 条记录标记为"续费"

---

## 📊 根本原因

### Creem 在一次购买中发送了多个 Webhook

从日志分析，Creem 在用户完成购买时发送了 **3 个事件**：

```
购买流程：
用户完成支付
  ↓
├─ Event 1: subscription.active（05:13:07）
│  └─ 我们未处理，返回 200
│
├─ Event 2: subscription.paid（05:13:07）
│  ├─ 我们处理了：调用 handleCheckoutCompleted
│  ├─ 查询订阅：无
│  ├─ 创建订阅（period_end: 2025-12-10）
│  └─ 记录历史：subscription_created ✅
│
└─ Event 3: checkout.completed（05:13:20）
   ├─ 我们处理了：调用 handleCheckoutCompleted
   ├─ 查询订阅：有！（Event 2 刚创建的）
   ├─ 判断：相同套餐 → 误判为续费
   ├─ 延长订阅（period_end: 2026-01-09）
   └─ 记录历史：subscription_renewed ❌ 错误
```

**问题**：
- `subscription.paid` 和 `checkout.completed` 都被处理
- 第 2 个事件创建了订阅
- 第 3 个事件检测到有订阅 → 误判为续费

---

## ✅ 修复方案

### 修复 1：添加幂等性检查

**在 `handleCheckoutCompleted` 开头添加**：

```typescript
async function handleCheckoutCompleted(data: any): Promise<boolean> {
  // ✅ 幂等性检查：使用支付 ID 去重
  const paymentId = data.id
  
  const { data: existingHistory } = await supabase
    .from("subscription_history")
    .select("id, event_type, creem_payment_id")
    .eq("creem_payment_id", paymentId)
    .maybeSingle()
  
  if (existingHistory) {
    console.log(`✅ Payment ${paymentId} already processed`)
    console.log(`Previous event: ${existingHistory.event_type}`)
    console.log("Skipping duplicate processing")
    return true  // 返回成功，但不重复处理
  }
  
  console.log(`✅ New payment ${paymentId}, proceeding`)
  
  // ... 原有处理逻辑
}
```

**效果**：
- 第 1 个处理：创建记录
- 第 2 个处理：检测到已处理 → 跳过
- ✅ 只产生 1 条记录

---

### 修复 2：区分首次购买和续费

**创建 `handleSubscriptionPaid` 函数**：

```typescript
async function handleSubscriptionPaid(data: any): Promise<boolean> {
  const subscriptionId = data.id
  
  // ✅ 检查是否已有此订阅
  const { data: existing } = await supabase
    .from("user_subscriptions")
    .select("id")
    .eq("creem_subscription_id", subscriptionId)
    .maybeSingle()
  
  if (!existing) {
    // 首次购买，跳过（等待 checkout.completed）
    console.log("💳 First payment - will be handled by checkout.completed")
    return true
  }
  
  // 已有订阅，这是续费
  console.log("🔄 Renewal payment for existing subscription")
  return await handleCheckoutCompleted(data)
}
```

**效果**：
- 首次购买：`subscription.paid` 跳过
- 自动续费：`subscription.paid` 处理

---

case "subscription.active":

## 🎯 修复细节

### 幂等性检查原理

**使用支付 ID 去重**：

```typescript
// 每个支付都有唯一的 ID
creem_payment_id: "ch_7QG64HCyuHuQKDsC94gAcs"

// 在 subscription_history 表中检查
SELECT * FROM subscription_history 
WHERE creem_payment_id = 'ch_7QG64HCyuHuQKDsC94gAcs'

// 如果已存在 → 跳过处理
```

**效果**：
- 即使收到多个相同的 webhook
- 也只处理一次
- 保证数据一致性

---

### 首次购买 vs 续费判断

**判断逻辑**：

```typescript
// 查询数据库
SELECT * FROM user_subscriptions 
WHERE creem_subscription_id = 'sub_xxx'

// 无记录 → 首次购买
// 有记录 → 续费
```

**为什么有效？**
- 首次购买时，`creem_subscription_id` 还未入库
- 续费时，`creem_subscription_id` 已存在
- 准确区分两种场景
