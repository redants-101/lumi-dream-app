### 4. ✅ 数据库 Schema

**文件**: `docs/3.定价支付/续费提醒系统完整.sql`

**表结构**：
```sql
renewal_reminders (
  id UUID PRIMARY KEY,
  subscription_id UUID,
  user_id UUID,
  reminder_type TEXT,  -- '7_days' | '3_days' | '1_day'
  sent_at TIMESTAMPTZ,
  email_to TEXT,
  email_sent BOOLEAN,
  email_id TEXT,
  UNIQUE(subscription_id, reminder_type)
)
```

## 🎯 工作流程

### 自动运行（生产环境）

```
每天上午 9 点（UTC）
    ↓
Vercel Cron Jobs 触发
    ↓
/api/cron/renewal-reminders 执行
    ↓
查询即将到期的订阅（7天、3天、1天）
    ↓
检查是否已发送提醒
    ↓
发送邮件（通过 Resend）
    ↓
记录到 renewal_reminders 表
    ↓
返回执行结果
```

### 手动触发（测试）

```bash
# 本地测试模式
curl "http://localhost:3000/api/cron/renewal-reminders?test=true"

# 生产测试（需要 Cron Secret）
curl -H "Authorization: Bearer ${CRON_SECRET}" \
     "https://www.lumidreams.app/api/cron/renewal-reminders"
```
