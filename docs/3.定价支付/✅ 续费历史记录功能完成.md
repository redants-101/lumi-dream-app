## 📄 已创建的文件

### 1. ✅ 数据库 Schema

**文件**: `docs/3.定价支付/续费历史记录系统.sql`

**表结构**: `subscription_history`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | UUID | 主键 |
| `subscription_id` | UUID | 关联订阅 |
| `user_id` | UUID | 关联用户 |
| `event_type` | TEXT | 事件类型 |
| `tier` | TEXT | 订阅层级 |
| `billing_cycle` | TEXT | 计费周期 |
| `amount` | DECIMAL | 交易金额 |
| `currency` | TEXT | 货币类型 |
| `creem_subscription_id` | TEXT | Creem 订阅 ID |
| `creem_payment_id` | TEXT | Creem 支付 ID |
| `period_start` | TIMESTAMPTZ | 周期开始 |
| `period_end` | TIMESTAMPTZ | 周期结束 |
| `description` | TEXT | 事件描述 |
| `status` | TEXT | 状态 |
| `event_date` | TIMESTAMPTZ | 事件时间 |

**事件类型**:
- `subscription_created` - 订阅创建
- `subscription_renewed` - 订阅续费成功
- `subscription_upgraded` - 订阅升级
- `subscription_downgraded` - 订阅降级
- `subscription_canceled` - 订阅取消
- `subscription_expired` - 订阅过期
- `payment_succeeded` - 支付成功
- `payment_failed` - 支付失败
- `refund_issued` - 退款

**辅助函数**:
- `get_user_subscription_history()` - 分页查询历史
- `get_user_total_spent()` - 总支付金额
- `get_user_renewal_count()` - 续费次数
- `get_recent_transactions()` - 最近交易

**触发器**:
- 自动记录订阅状态变更
- 自动记录层级升降级

## 📈 数据分析示例

### 按月统计收入

```sql
SELECT 
  DATE_TRUNC('month', event_date) as month,
  tier,
  COUNT(*) as transaction_count,
  SUM(amount) as total_revenue
FROM subscription_history
WHERE event_type IN ('payment_succeeded', 'subscription_renewed')
  AND status = 'completed'
GROUP BY DATE_TRUNC('month', event_date), tier
ORDER BY month DESC;
```

### 查询失败的支付

```sql
SELECT 
  user_id,
  tier,
  amount,
  description,
  event_date
FROM subscription_history
WHERE event_type = 'payment_failed'
  AND event_date >= NOW() - INTERVAL '30 days'
ORDER BY event_date DESC;
```

### 续费率分析

```sql
SELECT 
  tier,
  COUNT(DISTINCT user_id) as total_users,
  COUNT(CASE WHEN event_type = 'subscription_renewed' THEN 1 END) as renewals,
  (COUNT(CASE WHEN event_type = 'subscription_renewed' THEN 1 END)::float / NULLIF(COUNT(DISTINCT user_id), 0) * 100) as renewal_rate
FROM subscription_history
WHERE event_date >= NOW() - INTERVAL '6 months'
GROUP BY tier;
```

### 用户生命周期价值（LTV）

```sql
SELECT 
  user_id,
  COUNT(*) as total_transactions,
  SUM(amount) as lifetime_value,
  MIN(event_date) as first_payment,
  MAX(event_date) as last_payment,
  (EXTRACT(EPOCH FROM (MAX(event_date) - MIN(event_date))) / 86400)::int as days_as_customer
FROM subscription_history
WHERE event_type IN ('payment_succeeded', 'subscription_renewed')
  AND status = 'completed'
GROUP BY user_id
ORDER BY lifetime_value DESC
LIMIT 20;
```
