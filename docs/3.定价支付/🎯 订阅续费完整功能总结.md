## 📊 数据流转

### 订阅生命周期完整流程

```
┌─────────────┐
│ 用户注册     │ → Free 层级
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 用户订阅     │
└──────┬──────┘
       │
       ├─→ Creem 支付成功
       │   └─→ Webhook: checkout.completed
       │       └─→ 更新订阅状态为 active
       │           └─→ 记录历史：subscription_created
       │
       ▼
┌─────────────┐
│ 订阅激活     │ → Basic/Pro 层级
└──────┬──────┘
       │
       ├─→ 到期前 7 天 → 发送提醒邮件 📧
       ├─→ 到期前 3 天 → 发送提醒邮件 📧
       ├─→ 到期前 1 天 → 发送提醒邮件 📧
       │
       ▼
┌─────────────┐
│ 自动续费     │
└──────┬──────┘
       │
       ├─→ 续费成功 ✅
       │   └─→ Webhook: subscription.updated
       │       └─→ 更新周期时间
       │           └─→ 记录历史：subscription_renewed
       │               └─→ 回到"订阅激活"
       │
       └─→ 续费失败 ❌
           └─→ Creem 重试 3 次
               ├─→ 重试成功 → 同上
               │
               └─→ 全部失败
                   └─→ Webhook: subscription.expired
                       └─→ 更新状态为 expired
                           └─→ 降级为 Free
                               └─→ 发送失败通知邮件 📧
                                   └─→ 记录历史：subscription_expired

┌─────────────┐
│ 后台同步     │ → 每 6 小时运行一次
└──────┬──────┘
       │
       ├─→ 查询所有活跃订阅
       ├─→ 从 Creem 获取最新状态
       ├─→ 对比状态差异
       └─→ 自动修复不一致
           └─→ 记录同步日志
```

## 📊 数据库表总览

### 1. `user_subscriptions` - 订阅主表

存储用户当前的订阅状态。

**关键字段**:

- `tier` - 订阅层级
- `status` - 订阅状态
- `current_period_end` - 周期结束时间
- `creem_subscription_id` - Creem 订阅 ID

### 2. `subscription_history` - 订阅历史表

记录所有订阅和支付事件。

**关键字段**:

- `event_type` - 事件类型（9 种）
- `amount` - 交易金额
- `status` - 事件状态
- `event_date` - 事件时间

### 3. `renewal_reminders` - 续费提醒记录表

记录已发送的续费提醒，防止重复。

**关键字段**:

- `reminder_type` - 提醒类型（7_days/3_days/1_day）
- `sent_at` - 发送时间
- `email_to` - 收件人

### 4. `sync_logs` - 同步日志表

记录定期同步任务的执行情况。

**关键字段**:

- `sync_type` - 同步类型
- `total_checked` - 检查数量
- `updated` - 更新数量
- `errors` - 错误数量
- `duration_seconds` - 执行时长

## 🔄 Cron Jobs 配置

### Vercel Cron Jobs

**文件**: `vercel.json`

```json
{
  "crons": [
    {
      "path": "/api/cron/renewal-reminders",
      "schedule": "0 9 * * *"           // 每天上午 9 点
    },
    {
      "path": "/api/cron/sync-subscriptions",
      "schedule": "0 */6 * * *"          // 每 6 小时
    }
  ]
}
```

### 执行时间表

| Cron Job           | 频率      | 执行时间（UTC）            | 说明         |
| ------------------ | --------- | -------------------------- | ------------ |
| renewal-reminders  | 每天      | 09:00                      | 发送续费提醒 |
| sync-subscriptions | 每 6 小时 | 00:00, 06:00, 12:00, 18:00 | 同步订阅状态 |
