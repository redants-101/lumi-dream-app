## 🎯 功能概述

### 核心功能

- ✅ **自动检测** - 每天自动检查即将到期的订阅
- ✅ **分层提醒** - 到期前 7 天、3 天、1 天发送提醒
- ✅ **精美邮件** - 符合 Lumi 品牌风格的邮件模板
- ✅ **防重复发送** - 记录已发送的提醒，避免重复
- ✅ **自动续费说明** - 提醒用户自动续费，无需操作

### 提醒类型

| 时间点 | 提醒类型 | 邮件主题 | 触发方式 |
|--------|---------|---------|---------|
| 到期前 7 天 | `7_days` | 📅 Your subscription expires in 7 days | Cron Job 自动检测 |
| 到期前 3 天 | `3_days` | 🔔 Your subscription expires in 3 days | Cron Job 自动检测 |
| 到期前 1 天 | `1_day` | ⏰ Your subscription expires tomorrow | Cron Job 自动检测 |
| **续费失败** | `renewal_failed` | ⚠️ Your subscription renewal failed | **Webhook 触发** |

## 🚀 快速开始

### 步骤 1: 安装依赖

```bash
pnpm install resend @react-email/components tsx
```

### 步骤 2: 创建数据库表

在 Supabase SQL Editor 中运行：

```sql
-- 运行 docs/3.定价支付/续费提醒系统完整.sql
```

或手动创建：

```sql
CREATE TABLE IF NOT EXISTS renewal_reminders (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  subscription_id UUID NOT NULL REFERENCES user_subscriptions(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  reminder_type TEXT NOT NULL CHECK (reminder_type IN ('7_days', '3_days', '1_day')),
  sent_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  email_to TEXT NOT NULL,
  email_sent BOOLEAN DEFAULT true,
  email_id TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(subscription_id, reminder_type)
);
```

### 步骤 3: 配置环境变量

在 `.env.local` 中添加：

```bash
# Resend 邮件服务
RESEND_API_KEY=re_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
RESEND_FROM_EMAIL=noreply@lumidreams.app

# Cron Job 密钥
CRON_SECRET=your-random-secret-string-here
```

### 步骤 4: 配置 Vercel Cron Jobs

已在 `vercel.json` 中配置：

```json
{
  "crons": [
    {
      "path": "/api/cron/renewal-reminders",
      "schedule": "0 9 * * *"
    }
  ]
}
```

**说明**：`0 9 * * *` = 每天上午 9 点（UTC 时间）运行

### 步骤 5: 部署到 Vercel

```bash
git add .
git commit -m "feat: 添加续费提醒系统"
git push

# 在 Vercel 控制台配置环境变量
# RESEND_API_KEY
# RESEND_FROM_EMAIL
# CRON_SECRET
```

#### 1. 创建 Resend 账户

访问 https://resend.com/signup

1. 进入 Resend Dashboard → Domains
2. 点击 "Add Domain"
3. 输入你的域名（如 `lumidreams.app`）

#### 3. 创建 API Key

1. 进入 Resend Dashboard → API Keys
2. 点击 "Create API Key"
3. 选择权限：`Sending access`
4. 复制 API Key

#### 4. 配置发件人邮箱

```bash
RESEND_FROM_EMAIL=noreply@lumidreams.app
# 或使用子域名
RESEND_FROM_EMAIL=noreply@mail.lumidreams.app
```

### Cron Secret 配置

生成随机密钥：

```bash
# 方法 1: 使用 OpenSSL
openssl rand -base64 32

# 方法 2: 使用在线工具
# 访问 https://generate-secret.vercel.app/

# 方法 3: 使用 Node.js
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

将生成的密钥设置为 `CRON_SECRET` 环境变量。

### 提醒记录查询

```sql
-- 查看最近的提醒记录
SELECT 
  rr.reminder_type,
  rr.sent_at,
  rr.email_to,
  us.tier,
  us.billing_cycle,
  us.current_period_end
FROM renewal_reminders rr
JOIN user_subscriptions us ON us.id = rr.subscription_id
ORDER BY rr.sent_at DESC
LIMIT 20;
```

### 统计报表

```sql
-- 每日发送统计
SELECT 
  DATE(sent_at) as date,
  reminder_type,
  COUNT(*) as count
FROM renewal_reminders
WHERE sent_at >= NOW() - INTERVAL '30 days'
GROUP BY DATE(sent_at), reminder_type
ORDER BY date DESC;
```

## ⚠️ 续费失败通知

### 功能说明

当用户订阅续费支付失败时，系统会自动发送续费失败通知邮件。

### 触发条件

1. Creem 尝试自动扣款
2. 扣款失败（信用卡过期、余额不足等）
3. Creem 自动重试 3 次（1-3 天内）
4. 全部失败后发送 `subscription.expired` Webhook
5. 系统接收 Webhook 并发送邮件

### 邮件内容

续费失败邮件包含：
- ✅ 醒目的警告提示
- ✅ 失败详情（日期、原因）
- ✅ 降级影响说明（降为 Free 层级）
- ✅ 常见失败原因列表
- ✅ "更新支付方式"按钮
- ✅ 7 天内重新订阅提示
- ✅ 客服联系方式

### 实现细节

**文件**: `app/api/webhooks/creem/route.ts`

**处理流程**:
```typescript
async function handleSubscriptionExpired(data) {
  // 1. 查询订阅信息和用户邮箱
  const subscription = await supabase
    .from("user_subscriptions")
    .select("*, user:user_id(email, user_metadata)")
    .eq("creem_subscription_id", data.id)
    .single()

  // 2. 更新订阅状态为 expired，降级为 free
  await supabase
    .from("user_subscriptions")
    .update({
      status: "expired",
      tier: "free",
    })
    .eq("creem_subscription_id", data.id)

  // 3. 发送续费失败通知邮件
  await sendRenewalFailedEmail({
    to: user.email,
    userName: user.user_metadata?.full_name,
    tier: subscription.tier,
    billingCycle: subscription.billing_cycle,
    failureDate: new Date(),
    failureReason: data.reason || "Payment could not be processed",
  })
}
```

## ❓ 常见问题

### Q1: Cron Job 没有运行？

**检查清单**：
1. ✅ 是否已部署到 Vercel？（本地不会自动运行）
2. ✅ `vercel.json` 是否正确配置？
3. ✅ 环境变量 `CRON_SECRET` 是否设置？
4. ✅ 在 Vercel Dashboard → Cron Jobs 中查看执行日志

### Q2: 邮件发送失败？

**排查步骤**：
1. 检查 `RESEND_API_KEY` 是否正确
2. 确认发件域名已在 Resend 中验证
3. 检查 `RESEND_FROM_EMAIL` 格式是否正确
4. 查看 Resend Dashboard → Logs 了解失败原因

### Q3: 收到重复邮件？

**解决方法**：
- 检查 `renewal_reminders` 表中是否有重复记录
- 确认 `UNIQUE(subscription_id, reminder_type)` 约束生效
- 查看 Cron Job 是否被意外触发多次

### Q4: 如何自定义邮件内容？

**修改位置**：
- 邮件模板：`components/emails/renewal-reminder.tsx`
- 邮件服务：`lib/services/email-service.ts`

修改后重新部署即可生效。

### Q5: 如何更改提醒时间？

**修改 Cron 表达式**：

在 `vercel.json` 中修改 `schedule`：

```json
{
  "crons": [
    {
      "path": "/api/cron/renewal-reminders",
      "schedule": "0 10 * * *"  // 改为每天上午 10 点（UTC）
    }
  ]
}
```

**Cron 表达式格式**：

```
┌───────────── 分钟 (0 - 59)
│ ┌─────────── 小时 (0 - 23)
│ │ ┌───────── 日期 (1 - 31)
│ │ │ ┌─────── 月份 (1 - 12)
│ │ │ │ ┌───── 星期 (0 - 6, 0 = 周日)
│ │ │ │ │
* * * * *
```

**常用示例**：
- `0 9 * * *` - 每天上午 9 点
- `0 */6 * * *` - 每 6 小时一次
- `0 9 * * 1` - 每周一上午 9 点

### Q6: 如何添加新的提醒时间点？

1. **修改 API 路由**：

```typescript
// app/api/cron/renewal-reminders/route.ts
const reminders = [
  { days: 14, type: "14_days" as const },  // 新增：14 天前提醒
  { days: 7, type: "7_days" as const },
  { days: 3, type: "3_days" as const },
  { days: 1, type: "1_day" as const },
]
```

2. **更新数据库约束**：

```sql
ALTER TABLE renewal_reminders
  DROP CONSTRAINT renewal_reminders_reminder_type_check,
  ADD CONSTRAINT renewal_reminders_reminder_type_check
    CHECK (reminder_type IN ('14_days', '7_days', '3_days', '1_day'));
```

3. **更新邮件模板**：

在 `lib/services/email-service.ts` 的 `getEmailSubject()` 函数中添加新的提醒类型。
