## ⚠️ 备选方案日志（主方案失败时）

如果从 Supabase Auth 查询用户信息失败，会使用 Creem 提供的 customer_email：

```bash
# ... 前面的日志相同 ...

# ========== 邮件发送（备选方案）==========
[Webhook] Querying user info for confirmation email...
⚠️ [Webhook] Failed to query user info: User not found
[Webhook] Trying alternative method: from user_subscriptions...
[Webhook] Using customer email from Creem: user@example.com
✅ [Webhook] Confirmation email sent to: user@example.com

# ========== Webhook 完成 ==========
✅ [Webhook] Event processed successfully
POST /api/webhooks/creem 200 in 1456ms
```

**注意**：
- ⚠️ 这种情况下用户名会是邮箱前缀（如 "user"）
- ✅ 邮件仍然能够成功发送
- ✅ 不影响订阅激活

## 🐛 常见问题对照

### 问题 1：看不到邮件相关日志

**症状**：
```bash
✅ [Webhook] Subscription activated successfully!
✅ [Webhook] Subscription history recorded
# 然后直接结束，没有邮件日志
POST /api/webhooks/creem 200 in 500ms
```

**原因**：
- 代码未更新（服务器未重启）
- 缓存问题

**解决**：
```bash
# 1. 停止服务器（Ctrl+C）
# 2. 清除缓存
Remove-Item -Recurse -Force .next
# 3. 重启
pnpm dev
```

---

### 问题 2：显示邮件服务未启用

**症状**：
```bash
⚠️ [Email Service] RESEND_API_KEY not configured - email sending disabled
```

**原因**：
- `.env.local` 文件不存在或配置错误
- 环境变量未加载

**解决**：
1. 检查 `.env.local` 文件
2. 确认包含 `RESEND_API_KEY=re_xxxxx`
3. 重启服务器

---

### 问题 3：邮件发送失败

**症状**：
```bash
⚠️ [Webhook] Failed to send confirmation email
```

**原因**：
- API Key 无效
- 发件人邮箱未验证（生产环境）
- 网络问题

**检查**：
1. Resend Dashboard 中查看错误详情
2. 检查 API Key 是否正确
3. 检查发件人邮箱域名是否已验证

---

### 问题 4：用户信息查询失败

**症状**：
```bash
⚠️ [Webhook] Failed to query user info
[Webhook] Using customer email from Creem: xxx@xxx.com
```

**影响**：
- ✅ 邮件仍然能发送
- ⚠️ 用户名会是邮箱前缀

**不需要修复**：
- 这是正常的备选方案
- 不影响核心功能

## 📊 测试结果判定

### ✅ 测试通过标准

必须满足以下**所有**条件：

- [x] 日志显示 "Querying user info for confirmation email..."
- [x] 日志显示 "Sending confirmation email to: xxx@xxx.com"
- [x] 日志显示 "Confirmation email sent successfully"
- [x] Webhook 返回 200 状态码
- [x] Resend Dashboard 显示邮件已发送
- [x] 邮件状态为 "Delivered"

### ⚠️ 部分通过（可接受）

满足以下条件：

- [x] Webhook 返回 200 状态码
- [x] 订阅激活成功
- [x] 邮件发送相关日志存在
- [ ] 邮件实际发送失败（但不影响订阅）

**说明**：
- 核心功能正常（订阅激活）
- 邮件功能需要进一步排查

### ❌ 测试失败

出现以下情况：

- [ ] 没有任何邮件相关日志
- [ ] Webhook 返回 500 错误
- [ ] 订阅未激活

**需要**：
- 检查代码是否更新
- 重启服务器
- 清除缓存
