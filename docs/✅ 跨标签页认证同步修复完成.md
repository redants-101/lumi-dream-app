## 🐛 问题描述

### 原始问题

**场景**：
1. 用户在标签页 A 登录
2. 打开新标签页 B
3. 标签页 B 初始显示"未登录"状态（Sign In 按钮）
4. 1-2 秒后突然变为"已登录"状态（显示用户头像）

**根本原因**：
- 认证缓存 `lumi_auth_cache` 使用 **sessionStorage**
- sessionStorage 不跨标签页共享（每个标签页独立存储）
- 新标签页无法读取到其他标签页的缓存数据

**影响范围**：
- 导航栏用户按钮闪烁（Sign In ↔ 头像）
- 用户层级显示延迟（Anonymous → Free/Basic/Pro）
- 使用限制数字跳动（0 → 实际值）
- 用户体验不一致，感觉"卡顿"

---

## 🔧 解决方案

### 核心改动

#### 1. 将认证缓存从 sessionStorage 改为 localStorage

**原因**：
- ✅ localStorage 跨标签页共享
- ✅ 所有标签页读取同一份缓存数据
- ✅ 新标签页可以立即显示正确状态

**代码变更**：
```typescript
// ❌ 修改前：hooks/use-auth.ts
sessionStorage.setItem(AUTH_CACHE_KEY, JSON.stringify(cache))
sessionStorage.getItem(AUTH_CACHE_KEY)

// ✅ 修改后：hooks/use-auth.ts
localStorage.setItem(AUTH_CACHE_KEY, JSON.stringify(cache))
localStorage.getItem(AUTH_CACHE_KEY)
```

#### 2. 保持 5 分钟缓存有效期

**设计考虑**：
- ✅ 虽然使用 localStorage（永久存储）
- ✅ 但代码中实现了自动过期机制
- ✅ 缓存超过 5 分钟自动清除

**实现逻辑**：
```typescript
const { user: cachedUser, timestamp }: AuthCache = JSON.parse(cached)

// 检查缓存是否过期
if (Date.now() - timestamp < CACHE_DURATION) {
  return cachedUser  // 使用缓存
} else {
  localStorage.removeItem(AUTH_CACHE_KEY)  // 清除过期缓存
}
```

#### 3. 统一清理逻辑

**问题**：
- 之前清理逻辑分散在 `use-auth.ts` 和 `usage-limit-context.tsx` 两个文件
- 容易遗漏，不易维护

**改进**：
```typescript
// ✅ hooks/use-auth.ts - 统一清理函数
const clearAllUserData = () => {
  localStorage.removeItem(AUTH_CACHE_KEY)        // 认证缓存
  localStorage.removeItem(TIER_STORAGE_KEY)      // 用户层级
  localStorage.removeItem(USAGE_STORAGE_KEY)     // 使用数据
  // 保留 lumi-cookie-consent（用户偏好与账户无关）
}

const signOut = async () => {
  await fetch("/api/auth/logout", { method: "POST" })
  setUser(null)
  clearAllUserData()  // ✅ 一次性清理所有数据
}
```

**移除重复**：
```typescript
// ✅ contexts/usage-limit-context.tsx
// 移除了重复的 localStorage 清理代码
// 只保留 React 状态重置
if (prevAuth && !isAuthenticated) {
  // ✅ 注意：localStorage 清理已由 use-auth.ts 统一处理
  setSubscription(null)
  setUsageData(null)
  setIsLimitReached(false)
  // ...
}
```

## 📊 技术对比

### sessionStorage vs localStorage

| 特性 | sessionStorage | localStorage |
|------|---------------|--------------|
| **生命周期** | 标签页关闭即销毁 | 永久保存（除非手动清除） |
| **跨标签页** | ❌ 不共享（每个标签页独立） | ✅ 共享（同域名所有标签页） |
| **容量** | 5-10MB | 5-10MB |
| **适用场景** | 临时会话数据 | 长期缓存 + 跨标签页共享 |
| **安全性** | 高（自动清除） | 中（需手动清除） |

### 我们的选择

**修改前**：
```
lumi_auth_cache → sessionStorage（不跨标签页）
lumi_user_tier → localStorage（跨标签页）
lumi_usage_data_v2 → localStorage（跨标签页）
```

**修改后**：
```
lumi_auth_cache → localStorage（跨标签页） ✅
lumi_user_tier → localStorage（跨标签页）
lumi_usage_data_v2 → localStorage（跨标签页）
```

**优势**：
- ✅ 所有用户数据统一使用 localStorage
- ✅ 跨标签页完全一致
- ✅ 减少 API 调用（缓存命中率更高）

**安全保障**：
- ✅ 5 分钟自动过期（代码实现）
- ✅ 登出时主动清理（统一函数）
- ✅ 缓存数据不包含敏感信息（密码等）
