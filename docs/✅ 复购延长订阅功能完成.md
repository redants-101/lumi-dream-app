## 🎯 核心功能

### 1. 复购延长订阅时间 ✅

**场景**：用户已有 Basic Monthly，再次购买 Basic Monthly

**修改前** ❌：
```
原订阅：2025-11-01 → 2025-12-01（剩余 15 天）
再次购买：2025-11-15
结果：2025-11-15 → 2025-12-15（覆盖，损失前 14 天）
```

**修改后** ✅：
```
原订阅：2025-11-01 → 2025-12-01（剩余 15 天）
再次购买：2025-11-15
结果：2025-11-01 → 2025-12-31（延长 30 天，保留剩余时间）
```

### 2. 订阅历史记录类型区分 ✅

**修改前** ❌：
- 只有两种类型：`subscription_created`、`subscription_renewed`
- 无法区分升级、降级、换周期

**修改后** ✅：
- `subscription_created` - 首次购买
- `subscription_renewed` - 续费（相同套餐）
- `subscription_upgraded` - 升级（Basic → Pro）
- `subscription_downgraded` - 降级（Pro → Basic）
- `subscription_cycle_changed` - 换周期（Monthly ↔ Yearly）

## 📝 详细实现

### 核心逻辑流程

```typescript
// 1️⃣ 查询现有订阅
const { data: existingSubscription } = await supabase
  .from("user_subscriptions")
  .select("*")
  .eq("user_id", userId)
  .single()

// 2️⃣ 判断订阅类型
let eventType: string
if (!existingSubscription) {
  eventType = "subscription_created"  // 首次购买
} else {
  const oldTier = existingSubscription.tier
  const oldCycle = existingSubscription.billing_cycle
  const newTier = tierInfo.tier
  const newCycle = tierInfo.billingCycle

  if (oldTier === newTier && oldCycle === newCycle) {
    eventType = "subscription_renewed"  // 相同套餐
  } else if (oldTier === newTier && oldCycle !== newCycle) {
    eventType = "subscription_cycle_changed"  // 换周期
  } else if (tierLevel[newTier] > tierLevel[oldTier]) {
    eventType = "subscription_upgraded"  // 升级
  } else {
    eventType = "subscription_downgraded"  // 降级
  }
}

// 3️⃣ 计算订阅周期（延长逻辑）
if (isSamePlan && existingSubscription) {
  // ✅ 相同套餐：从现有结束时间延长
  const existingEnd = new Date(existingSubscription.current_period_end)
  
  if (existingEnd > now) {
    // 从结束时间延长
    periodEnd = new Date(existingEnd)
    periodEnd.setDate(periodEnd.getDate() + daysToAdd)
  } else {
    // 已过期，从现在开始
    periodEnd = new Date(now.getTime() + daysToAdd * 24 * 60 * 60 * 1000)
  }
} else {
  // 新购或升级/降级：从现在开始
  periodEnd = new Date(now.getTime() + daysToAdd * 24 * 60 * 60 * 1000)
}

// 4️⃣ 记录历史（包含旧订阅信息）
await supabase
  .from("subscription_history")
  .insert({
    event_type: eventType,
    description: description,
    metadata: existingSubscription ? {
      old_tier: existingSubscription.tier,
      old_billing_cycle: existingSubscription.billing_cycle,
      old_period_end: existingSubscription.current_period_end,
    } : undefined,
  })
```

## 📊 订阅历史记录详解

### 历史记录字段

```typescript
{
  subscription_id: number        // 订阅记录 ID
  user_id: string               // 用户 ID
  event_type: string            // ✅ 事件类型（新增详细区分）
  tier: string                  // 新套餐层级
  billing_cycle: string         // 新计费周期
  amount: number                // 金额
  currency: string              // 货币
  period_start: string          // 周期开始
  period_end: string            // 周期结束
  description: string           // ✅ 详细描述
  status: string                // 状态
  event_date: string            // 事件时间
  metadata: object              // ✅ 元数据（保存旧订阅信息）
}
```

### 事件类型说明

| 事件类型 | 触发条件 | 描述示例 | 元数据 |
|---------|---------|---------|--------|
| `subscription_created` | 首次购买 | `basic monthly subscription created` | 无 |
| `subscription_renewed` | 相同套餐续费 | `basic monthly subscription renewed (extended)` | 包含旧订阅信息 |
| `subscription_upgraded` | 升级到更高层级 | `Upgraded from basic to pro` | `old_tier: "basic"` |
| `subscription_downgraded` | 降级到更低层级 | `Downgraded from pro to basic` | `old_tier: "pro"` |
| `subscription_cycle_changed` | 更换计费周期 | `Changed basic from monthly to yearly` | `old_billing_cycle: "monthly"` |

### 元数据结构

```typescript
// ✅ 保存旧订阅信息（如果存在）
metadata: {
  old_tier: "basic",                    // 旧套餐层级
  old_billing_cycle: "monthly",         // 旧计费周期
  old_period_end: "2025-12-01T00:00:00Z" // 旧订阅结束时间
}
```

**用途**：
- 追踪订阅变更历史
- 用户权益审计
- 退款/争议处理
- 数据分析

## ⚖️ 剩余时间处理策略

### 当前策略

| 场景 | 剩余时间处理 | 原因 |
|------|------------|------|
| **续费**（相同套餐） | ✅ 延长（保留） | 用户应获得全部时间 |
| **升级**（Basic → Pro） | ❌ 不保留 | 立即享受 Pro 功能 |
| **降级**（Pro → Basic） | ❌ 不保留 | 用户主动降级 |
| **换周期**（Monthly ↔ Yearly） | ❌ 不保留 | 订阅类型变更 |

### 未来优化方向（可选）

#### 升级时按比例抵扣

```typescript
// 计算剩余价值
const remainingDays = Math.ceil((oldPeriodEnd - now) / (24 * 60 * 60 * 1000))
const oldDailyRate = oldPrice / oldCycleDays
const remainingValue = remainingDays * oldDailyRate

// 抵扣新订阅
const newDailyRate = newPrice / newCycleDays
const creditDays = Math.floor(remainingValue / newDailyRate)

// 新订阅周期 = 标准周期 + 抵扣天数
periodEnd.setDate(periodEnd.getDate() + newCycleDays + creditDays)
```

**示例**：
```
Basic Monthly：$4.99/30天 = $0.166/天
剩余 15 天 = $2.49 价值

Pro Monthly：$9.99/30天 = $0.333/天
抵扣：$2.49 / $0.333 = 7.5 天

新周期：30 天 + 7 天 = 37 天
```
