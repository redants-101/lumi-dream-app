# 🧪 购买确认邮件测试指南

## ✅ 已完成的修改

### 修改内容

在 `app/api/webhooks/creem/route.ts` 中添加了订阅确认邮件发送功能：

1. **导入邮件服务**
   ```typescript
   import { sendSubscriptionConfirmationEmail } from "@/lib/services/email-service"
   ```

2. **查询用户信息**
   - 使用 `supabase.auth.admin.getUserById()` 查询用户
   - 获取 `email` 和 `user_metadata`
   - 备选方案：使用 Creem 提供的 `customer_email`

3. **发送确认邮件**
   - 在订阅激活成功后自动发送
   - 包含用户名、套餐信息
   - 错误不影响订阅激活

## 🐛 常见问题排查

### 问题 1：未发送邮件

**日志显示**：
```bash
⚠️ [Email Service] RESEND_API_KEY not configured - email sending disabled
```

**解决方案**：
1. 检查 `.env.local` 中的 `RESEND_API_KEY`
2. 确认环境变量格式正确（无空格、换行）
3. 重启服务器

---

### 问题 2：用户信息查询失败

**日志显示**：
```bash
⚠️ [Webhook] Failed to query user info: ...
[Webhook] Trying alternative method: from user_subscriptions...
```

**原因**：
- `supabase.auth.admin.getUserById()` 失败
- 可能是用户 ID 不存在或权限问题

**解决方案**：
- 代码会自动使用备选方案（customer_email）
- 检查 `SUPABASE_SERVICE_ROLE_KEY` 是否配置正确

**预期行为**：
- 备选方案会使用 Creem 提供的 `customer_email`
- 仍然能发送邮件，但用户名会是邮箱前缀

---

### 问题 3：邮件发送失败

**日志显示**：
```bash
⚠️ [Webhook] Failed to send confirmation email to: user@example.com
```

**检查**：
1. Resend API Key 是否有效
2. 发件人邮箱是否正确
3. Resend Dashboard 中查看错误详情

**常见原因**：
- 测试邮箱限制（不能发送到真实用户）
- API 配额用完
- 域名未验证（生产环境）

---

### 问题 4：用户收不到邮件

**即使日志显示成功**：

1. **检查垃圾邮件文件夹**
2. **检查 Resend Dashboard**
   - 邮件状态是否为 `Delivered`
   - 如果是 `Bounced`，说明邮箱地址无效
3. **测试环境限制**
   - 使用 `onboarding@resend.dev` 时，只能发送到特定邮箱
